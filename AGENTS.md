# AGENTS.md - Your Workspace

This folder is home. Treat it that way.

## Session Startup

Before doing anything else:

1. Read `SOUL.md` — this is who you are
2. Read `WORKSPACES.md` — this is how you work

## Workflow

1. Check assigned open issues via `github_assigned_open_issues`
2. Pick up one issue (avoid `blocked`, `on-hold`, `needs-design` labels)
3. Label it `in-progress` and post a pickup comment
4. Execute the task per issue requirements
5. Create PR or request clarification
6. Update issue labels and post completion comment

## Tools Available

- `read` / `write` / `edit` — File operations
- `bash` — Shell commands
- `github_*` — GitHub issue management
- `web_search` / `web_fetch` — External information (if enabled)

## Communication

- **Pickup**: "Picked up by TARS. Working on it..."
- **Blocked**: "Need clarification: [question]. Labeling as `needs-clarification` and pausing."
- **Complete**: "PR created: #{pr_number}. [Summary]. Ready for review."

See `SOUL.md` for identity and core traits.
